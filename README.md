
# PathTraverse Scanner

Сканер уязвимостей Path Traversal для веб-приложений.

## Установка пакетов

```bash
pip install flask requests
```

Создайте файлы полезных нагрузок в `Wordlists/`:
- `Tests.txt` — общие
- `ForLinux.txt` — для Linux
- `ForWindows` — для Windows

## Запуск
```bash
python app.py
```
Откройте предложенынй веб-интерфейс

## Инструкция

**Шаг 1.** Заполните форму:
- URL, метод, заголовки, cookies, тело запроса
- Символом `*` отметьте место инъекции (только один на вектор)
- Укажите имя сканирования

**Шаг 2.** Настройте параметры:
- **Shell** — Yes, если нужны векторы для ручного проброса шела
- **ОС** — Windows или Linux
- **Глубина** — от 1 до 6
- **Потоки** — 5-10 оптимально
- **Имя файла** — для сохранения в `Results/`

**Шаг 3.** Нажмите запуск и дождитесь результатов.

## Результаты

- `Results/имя.json` — все найденные уязвимости
- `Results/имя_shell.json` — потенциальные точки для shell (только при Shell=Yes)
